# Restaurant AI Insights — demo

Simulador de decisões para pequenos restaurantes de delivery: antes de dar um desconto, mudar preço
ou equipe, veja se a conta fecha e se a cozinha dá conta. Dados fictícios.

Esta demo roda no modo por regras, sem o modelo local (Ollama). O assistente de decisões interpreta
as perguntas por regras e responde com os números calculados pelo simulador.

Código, testes e documentação: <https://github.com/GabrieliModollo/restaurant-ai-insights>.
Esta cópia é publicada automaticamente a partir da branch `main`.
